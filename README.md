
# Selenium Tests for iFrames and Nested Frames

## Project Overview
This project implements automated browser testing for iFrames and Nested Frames using Selenium WebDriver, Java and TestNG.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- Google Chrome
- Visual Studio Code

## Test Cases

### 1. iFrame Testing
- Open the iFrame webpage.
- Switch to the iFrame.
- Read and verify the editor text.
- Return to the main webpage.

### 2. Nested Frame Testing
- Switch to the top frame.
- Verify Left, Right and Middle frames.
- Switch to the Bottom frame.
- Verify frame contents.

## How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Run:

   mvn test
